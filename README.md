# KT_33

# Вариант 1. Телефонная книга
1) Dictionary<string, string> phoneBook — имя → номер телефона.
2) Метод безопасного поиска номера по имени через TryGetValue, с понятным сообщением, если имени нет.
3) Метод обновления номера для существующего имени.
4) Метод удаления записи по имени через Remove, с проверкой результата.
5) Переберите всю книгу через foreach, используя KeyValuePair<string, string>.

# Ограничения
Чтение значения по потенциально отсутствующему ключу обязано идти через TryGetValue или ContainsKey — прямое обращение через индексатор без предварительной проверки, которое могло бы бросить KeyNotFoundException, не засчитывается.
